ClaudeFit은 Claude Code 공식 문서를 "이론 → 실습 → 반복 복습" 사이클로 체득하는 비공식 학습 트레이닝 앱입니다.

운동하듯 매일 조금씩, 확실하게 실력을 쌓으세요. 터미널 명령어를 외우는 게 아니라 직접 손으로 눌러보고, 틀린 문제는 간격 반복으로 다시 만나며 체화합니다.

■ 원문 라이브러리
Claude Code 공식 문서 한국어판 220페이지를 기기에 캐시해 오프라인에서도 전문 검색이 가능합니다.

■ 학습 트랙 (5개 트랙 · 38개 모듈)
입문 → 일상 사용 → 커스터마이즈 → 자동화·병렬 → 숙련·운영까지, 실무에 필요한 순서 그대로 구성했습니다.

■ 퀴즈 & 실습
객관식·복수선택·순서배열 문항으로 이해도를 확인하고, 틀리면 바로 원문 해당 위치로 연결되는 해설을 확인할 수 있습니다.

■ 브라우저 터미널 시뮬레이터
실제 Claude Code CLI를 흉내 낸 9개 시나리오(첫 세션, 권한 모드, plan 승인, 세션 관리, 체크포인트, git, 코드 리뷰, 진단 등)를 화면 안에서 직접 타이핑하며 연습합니다.

■ ConfigForge
settings.json / CLAUDE.md / SKILL.md / 서브에이전트 / .mcp.json / 훅 설정을 실제로 작성하고 즉시 채점받는 8개 실전 과제입니다.

■ 데일리 드릴
SM-2 기반 간격 반복 알고리즘이 복습 기한이 지난 문항과 내 약점 스킬의 신규 문항을 매일 자동으로 섞어 추천합니다.

■ 대시보드
트랙별 진도, 스킬별 숙련도, 연속 학습일을 한눈에 확인하고 진도를 내보내기/가져오기로 백업할 수 있습니다.

■ 개인정보
모든 학습 기록은 기기 안에만 저장됩니다. 광고, 분석 SDK가 없고 어떤 개인정보도 외부로 전송하지 않습니다.
