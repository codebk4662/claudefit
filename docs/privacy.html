ClaudeFit 개인정보처리방침

최종 수정일: 2026-10-10

요약

ClaudeFit은 Claude Code 공식 문서를 학습하기 위한 비공식 학습 앱입니다. 어떠한 개인정보도 수집하지 않습니다. 학습 진도, 퀴즈 기록, 스킬 숙련도 등 모든 데이터는 오직 사용자의 기기 안(localStorage)에만 저장되며, 어떤 서버로도 전송되지 않습니다.

수집하는 개인정보

없습니다. 이름, 이메일, 위치, 광고 식별자 등 어떤 개인 식별 정보도 수집·저장·전송하지 않습니다.

기기에 저장되는 데이터

학습 진도, 완료한 모듈, 퀴즈 정답 기록, 스킬별 숙련도, 복습 일정 등은 사용자가 직접 "진도 내보내기" 기능으로 내려받지 않는 한 오직 기기 로컬 저장소에만 남습니다. 앱을 삭제하거나 기기 설정에서 앱 데이터를 지우면 모든 기록이 함께 삭제됩니다.

네트워크 통신

앱은 Claude Code 공식 문서(code.claude.com)의 정적 사본을 로컬에 캐시하기 위한 콘텐츠만 내려받습니다. 이 과정에서 사용자를 식별할 수 있는 정보는 전송되지 않습니다.

제3자 서비스

광고 SDK, 분석(애널리틱스) SDK, 크래시 리포팅 SDK 등 어떤 제3자 추적 도구도 포함되어 있지 않습니다.

아동의 개인정보

본 앱은 개인정보를 전혀 수집하지 않으므로, 연령과 무관하게 모든 사용자에게 동일하게 적용됩니다.

방침 변경

본 방침은 사전 고지 없이 변경될 수 있으며, 변경 사항은 이 페이지에 즉시 반영됩니다.
